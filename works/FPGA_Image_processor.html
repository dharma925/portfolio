FPGA Image Processor

A convolution engine on FPGA — an image, a kernel, and hardware doing the multiply-accumulate across every pixel neighborhood. Still being built out.

This is an FPGA implementation of image convolution: taking an input image and a kernel (a small weight matrix — the same operation a CNN's convolutional layer performs), and computing the convolution in hardware rather than in software. The project is in Vivado, written primarily in VHDL with some Verilog for supporting logic.

The test input is a grayscale bitmap converted from a source image, feeding an output_buffer IP block that assembles the processed result. As of the last update, some of the integration between blocks is still in progress — this one's an active work in progress, not a finished pipeline, and this page will get a real writeup once it is.

Source, current state, and commit history are on GitHub.
